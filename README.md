#### 🏛️ GestiCAB V3 — Plataforma multi-tenant

Refactorización de una plataforma legacy para la **gestión de inscripciones y control de aforo de eventos municipales**, migrándola hacia una arquitectura desacoplada basada en **DTOs y Servicios de Dominio**.

Principales aportaciones:

- Arquitectura backend con **Laravel / PHP** y frontend con **Vue**.
- Control de concurrencia mediante bloqueos pesimistas con `lockForUpdate`.
- Servicio de bloqueo mediante *heartbeat lock*.
- Aislamiento de datos en arquitectura **multi-tenant**.
- **CSP** con nonces dinámicos y **HSTS**.
- Autorización **RBAC** mediante más de 20 middlewares personalizados.
- 60 migraciones de base de datos sobre **MySQL 8.0**.
- Pipeline automatizado de **CI/CD con GitHub Actions**.
- Ejecución de pruebas sobre entornos **MySQL y SQLite**.
- **174 tests automatizados** entre unitarios, feature y smoke.
- **566 aserciones con un 100 % de éxito**.

`PHP` `Laravel` `Vue` `MySQL` `PHPUnit` `GitHub Actions` `Docker`
